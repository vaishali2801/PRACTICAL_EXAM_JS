📝 Task Manager Web Application

A simple, user-friendly Task Manager built using HTML, CSS, JavaScript, and Bootstrap.
This project allows users to add, edit, delete, and filter tasks by priority, with data saved in Local Storage so tasks remain even after page refresh.

🚀 Features

➕ Add new tasks with description and priority

✏️ Edit existing tasks

🗑️ Delete tasks

🎯 Filter tasks by priority (High / Medium / Low)

💾 Persistent data using Local Storage

📱 Responsive and attractive UI

🎓 Beginner-friendly & exam-ready structure

🛠️ Technologies Used

HTML5 – Structure of the application

CSS3 – Styling and layout

JavaScript (ES6) – Logic and functionality

Bootstrap 5 – Responsive design and components

Local Storage – Data persistence in browser

⚙️ How the Application Works

User enters:

Task name

Task description

Task priority

Clicks Save Task

Task is displayed in the table

User can:

Edit the task

Delete the task

Filter tasks using priority dropdown

All data is stored in Local Storage

Functions
